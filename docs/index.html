How it works

Four steps, zero manual entry

The entire pipeline runs locally. Your bank data never leaves your machine.

01
📄
Upload PDF
Drop your bank statement PDF into the Streamlit UI. Supports all major Indian banks.
02
🤖
AI Extraction
Deterministic pdfplumber parsers handle known banks. Groq LLM fallback handles everything else.
03
✏️
Review & Edit
Every transaction shows in an editable table. Correct any ledger assignment before export.
04
📦
Download XML
One click exports a standards-compliant Tally XML file ready to import into Tally ERP 9 or Tally Prime.

MethodEndpointDescription

Get Started

Two ways to run Bally AI

Windows installer for end users. Docker or local Python for developers.

Windows Installer
1. Download BallyAI-Setup.exe from Releases 2. Run installer, click Next, Next, Finish 3. Enter your free Groq API key on first launch 4. Browser opens automatically No Python. No terminal. No setup.
Docker / Local Dev
$ git clone github.com/jishanahmed-shaikh/bally-ai $ cp .env.example .env # add GROQ_API_KEY $ docker-compose up --build API http://localhost:8000/docs UI http://localhost:8501
